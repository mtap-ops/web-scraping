#Web Scraping Basics

A beginner-friendly project for learning the basics of web scraping with Python.

**What is web scraping?**

Web scraping is the process of automatically collecting data from websites. 
Instead of copying information by hand, a script downloads a web page, finds the 
parts you care about (titles, prices, links, tables) and saves them in a useful format
